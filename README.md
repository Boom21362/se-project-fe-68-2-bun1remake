## Overview

This project is a sophisticated frontend web application, developed as part of a Software Engineering curriculum. It leverages the power of Next.js for a performant and scalable user experience, complemented by React for building dynamic interfaces. The application incorporates a modern development ecosystem, featuring robust state management with Redux Toolkit, elegant UI components from Material-UI, and efficient styling with Tailwind CSS. It is designed for extensibility, maintainability, and comprehensive testing, ensuring a high-quality codebase.

## Features

-   **Modern Frontend Architecture:** Built with [Next.js](https://nextjs.org/) for optimized performance and developer experience, supporting SSR, SSG, or ISR.
-   **Rich User Interface:** Utilizes [Material-UI (MUI)](https://mui.com/) components for a polished and consistent design, enhanced by [Emotion](https://emotion.sh/) for styling.
-   **Responsive & Customizable Styling:** Employs [Tailwind CSS](https://tailwindcss.com/) for a utility-first approach to create responsive and easily customizable layouts.
-   **Centralized State Management:** Implements [Redux Toolkit](https://redux-toolkit.js.org/) and [Redux Persist](https://github.com/rt2zz/redux-persist) for predictable and persistent state management across the application.
-   **Robust Form Handling:** Features [React Hook Form](https://react-hook-form.com/) with [Yup](https://github.com/jquense/yup) schema validation for efficient and reliable form submission and data integrity.
-   **Date & Time Management:** Integrated with [Day.js](https://day.js.org/) and [MUI X Date Pickers](https://mui.com/x/react-date-pickers/) for intuitive date and time selections.
-   **API Communication:** Utilizes [Axios](https://axios-http.com/) for making efficient and streamlined HTTP requests to external APIs.
-   **Component-Driven Development:** [Storybook](https://storybook.js.org/) integration for isolated UI component development, testing, and documentation.
-   **Comprehensive Testing:** Includes [Jest](https://jestjs.io/) for unit/integration tests and [Playwright](https://playwright.dev/) for reliable end-to-end testing.
-   **Type-Safe Development:** Written entirely in [TypeScript](https://www.typescriptlang.org/) for enhanced code quality and maintainability.
-   **Containerization Support:** Comes with a [Dockerfile](https://docs.docker.com/) for easy deployment and consistent environments.

## Quick Start

### Prerequisites
Before you begin, ensure you have the following installed:
-   [Node.js](https://nodejs.org/en/) (LTS recommended)
-   [npm](https://www.npmjs.com/) (Node Package Manager)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Boom21362/se-project-fe-68-2-bun1remake.git
    cd se-project-fe-68-2-bun1remake
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Environment setup**
    Create a `.env.local` file in the root directory by copying the example:
    ```bash
    cp .env.local.example .env.local
    ```
    Then, open `.env.local` and configure your environment variables.
    For example:
    ```
    # NEXT_PUBLIC_API_URL=http://localhost:8000/api
    # MOCK_API_BASE_URL=http://localhost:3001
    # OTHER_CONFIG_VAR=some_value
    ```

4.  **Start development server**
    ```bash
    npm run dev
    ```

5.  **Open your browser**
    Visit `http://localhost:3000` (or the port indicated by the `npm run dev` output).

## Configuration

### Environment Variables
The application uses environment variables for sensitive data and configuration that varies between environments. Refer to `.env.local.example` for a list of variables.

| Variable             | Description                                    | Required |
|----------------------|------------------------------------------------|----------|
| `NEXT_PUBLIC_API_URL`| The base URL for the public-facing API.        | No       |
| `MOCK_API_BASE_URL`  | The base URL for any mock API used in development.| No       |
| `OTHER_CONFIG_VAR`   | Example of another configuration variable.     | No       |

### Configuration Files
-   `next.config.ts`: Next.js specific configurations, including image optimization, routing, and webpack settings.
-   `postcss.config.mjs`: PostCSS configuration, primarily used for Tailwind CSS processing.
-   `jest.config.js`: Configuration for the Jest testing framework.
-   `playwright.config.ts`: Configuration for Playwright end-to-end tests.
-   `tsconfig.json`: TypeScript compiler options for the project.

## Development

### Available Scripts
In the project directory, you can run:

| Command             | Description                                          |
|---------------------|------------------------------------------------------|
| `npm run dev`       | Starts the development server.                       |
| `npm run build`     | Builds the application for production.               |
| `npm run start`     | Starts the production server after building.         |
| `npm run lint`      | Runs ESLint to check for code quality and style issues.|
| `npm run test`      | Runs Jest unit/integration tests.                     |
| `npm run test:watch`| Runs Jest tests in watch mode for continuous testing.|
| `npm run e2e`       | Runs Playwright end-to-end tests.                    |
| `npm run storybook` | Starts Storybook for isolated UI component development.|
| `npm run build-storybook` | Builds the Storybook static site.                |

### Development Workflow
1.  Ensure all prerequisites are installed.
2.  Clone the repository and install dependencies (`npm install`).
3.  Set up environment variables in `.env.local`.
4.  Start the development server with `npm run dev`.
5.  Develop components and features, leveraging Storybook (`npm run storybook`) for isolated UI work.
6.  Run tests regularly (`npm run test`, `npm run e2e`).
7.  Ensure code quality with linting (`npm run lint`).

## Deployment

### Production Build
To create a production-ready build of the application:
```bash
npm run build
```
This command compiles the Next.js application, optimizing it for performance and bundle size. The output is placed in the `.next` directory.

### Deployment Options
-   **Vercel:** The project is configured for seamless deployment on [Vercel](https://vercel.com/), as indicated by the `homepage` URL. Simply push your changes to the `main` branch, and Vercel will automatically deploy.
-   **Docker:** A `Dockerfile` is provided for containerizing the application, allowing for consistent deployments across various environments.
    ```bash
    # Build the Docker image
    docker build -t se-project-fe-68-2-bun1remake .

    # Run the Docker container
    docker run -p 3000:3000 se-project-fe-68-2-bun1remake
    ```
